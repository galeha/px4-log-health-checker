# PX4 日志飞行健康检查器

面向普通 PX4 多旋翼用户的中文飞行日志健康检查工具。

## 首版目标

用户在本机导入一份 PX4 `.ulg` 日志后，先查看五项中文健康结论；点击某项再查看曲线、原始指标、判定依据和相关参数说明：

- 振动
- GPS 状态
- 电池压降
- 姿态跟踪
- 电机输出余量

## 边界

- 首版仅支持 PX4 多旋翼 ULog（`.ulg`）。
- 日志只在本机解析，不上传、不建立账户、不保存历史记录。
- 结论使用可追溯的规则和阈值生成；缺少关键数据时明确显示“数据不足”。
- 本工具用于飞后维护排查，不能替代飞前检查、机体检查或飞行安全决策。
